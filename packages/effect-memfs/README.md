# @systemfsoftware/effect-memfs

In-memory FileSystem for @effect/platform.

## Install

```sh
pnpm add @systemfsoftware/effect-memfs effect
```

Its peer dependencies, `effect@^4` and `typescript@>=5.0.0`, come from your project: this package declares them but
does not install them, so one copy is shared with the rest of your project.

## Entry points

- `@systemfsoftware/effect-memfs`

## API

The public surface is generated from the source and versioned with the package: [`etc/effect-memfs.api.md`](./etc/effect-memfs.api.md).
